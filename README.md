## References and Acknowledgments
This visualization project is based on the following github repository: https://github.com/graphdeco-inria/gaussian-splatting and https://github.com/lzhnb/GS-IR.
## Introduction
We clone and resolved some issues with [GS-IR](https://github.com/lzhnb/GS-IR) and created a visualization system for its rendering.For different datasets, we referred to the "convert.py" method in the [gaussian-splatting](https://github.com/graphdeco-inria/gaussian-splatting) project and used COLMAP to preprocess non-standard datasets to achieve the best effect of relighting rendering.
